Solution de persistance Tails OS

Gardez vos applications AppImage actives après redémarrage

Un script Bash interactif spécialement conçu pour Tails OS. Téléchargez, configurez et intégrez automatiquement vos AppImages directement dans le menu principal d'affichage GNOME de manière 100% permanente.

Bash Shell Script Compatible Tails OS 5 & 6 Support AppImage Portable Persistance Dotfiles
install_appimage.sh 
#!/usr/bin/env bash

# ==============================================================================
# Assistant d'installation d'AppImage pour Tails OS avec Persistance
# ==============================================================================

# Dossiers de destination dans le stockage persistant
APP_DIR="$HOME/Persistent/Apps"
DESKTOP_DIR="/live/persistence/TailsData_unlocked/dotfiles/.local/share/applications"

# Vérification si la persistance est bien activée
if [ ! -d "$HOME/Persistent" ]; then
    echo "[!] Erreur : Le stockage persistant n'est pas activé ou déverrouillé."
    exit 1
fi

mkdir -p "$APP_DIR"
mkdir -p "$DESKTOP_DIR"

echo "=== Assistant d'installation AppImage pour Tails OS ==="
echo ""

# Menu de sélection du mode
echo "1) Télécharger une AppImage via une URL"
echo "2) Utiliser un fichier AppImage déjà présent"
read -rp "Choix [1/2] : " CHOICE

if [ "$CHOICE" -eq 1 ]; then
    read -rp "Entrez l'URL de l'AppImage : " APP_URL
    read -rp "Nom du fichier final (ex: MonApp.AppImage) : " APP_FILENAME
    
    # Correction de l'extension si absente
    [[ "$APP_FILENAME" != *.AppImage ]] && APP_FILENAME="${APP_FILENAME}.AppImage"
    
    DEST_PATH="$APP_DIR/$APP_FILENAME"
    echo "[*] Téléchargement en cours..."
    curl -L "$APP_URL" -o "$DEST_PATH"
    
elif [ "$CHOICE" -eq 2 ]; then
    read -rp "Chemin vers votre fichier .AppImage : " LOCAL_PATH
    
    # Nettoyage des guillemets éventuels
    LOCAL_PATH="${LOCAL_PATH//\'/}"
    LOCAL_PATH="${LOCAL_PATH//\"/}"

    if [ ! -f "$LOCAL_PATH" ]; then
        echo "[!] Fichier introuvable : $LOCAL_PATH"
        exit 1
    fi
    
    APP_FILENAME=$(basename "$LOCAL_PATH")
    DEST_PATH="$APP_DIR/$APP_FILENAME"
    
    if [ "$LOCAL_PATH" != "$DEST_PATH" ]; then
        cp "$LOCAL_PATH" "$DEST_PATH"
        echo "[*] Fichier copié dans $APP_DIR"
    fi
else
    echo "[!] Choix invalide."
    exit 1
fi

# Autoriser l'exécution
chmod +x "$DEST_PATH"
echo "[+] Fichier rendu exécutable (chmod +x)."

# Informations pour le raccourci .desktop
echo ""
echo "=== Configuration du raccourci dans le menu ==="
read -rp "Nom affiché dans le menu (ex: Mon Application) : " APP_NAME
read -rp "Nom du fichier .desktop (ex: monapp.desktop) : " DESKTOP_FILENAME
read -rp "Catégorie (ex: Utility, Network, System) [Utility] : " APP_CAT
APP_CAT=${APP_CAT:-Utility}

[[ "$DESKTOP_FILENAME" != *.desktop ]] && DESKTOP_FILENAME="${DESKTOP_FILENAME}.desktop"
DESKTOP_FILE_PATH="$DESKTOP_DIR/$DESKTOP_FILENAME"

# Génération dynamique du fichier .desktop persistant
cat <<EOF > "$DESKTOP_FILE_PATH"
[Desktop Entry]
Version=1.0
Type=Application
Name=$APP_NAME
Exec=$DEST_PATH
Icon=exec
Terminal=false
Categories=$APP_CAT;
EOF

chmod +x "$DESKTOP_FILE_PATH"

echo ""
echo "[✔] Installation terminée avec succès !"
echo "• AppImage stockée dans : $DEST_PATH"
echo "• Raccourci créé dans  : $DESKTOP_FILE_PATH"

Guide d'utilisation étape par étape

Suivez ces 4 étapes pour installer et conserver vos applications AppImage sur Tails.

1

Activer le Stockage Persistant

Allez dans Applications → Tails → Persistent Storage. Activez au minimum :

  • Personal Data
  • Dotfiles
2

Créer le fichier Script

Copiez le script ci-dessus et enregistrez-le dans votre dossier persistant :

~/Persistent/install_appimage.sh
3

Rendre le script exécutable

Ouvrez un terminal GNOME et accordez les permissions d'exécution :

chmod +x ~/Persistent/install_appimage.sh
4

Exécuter l'assistant

Lancez le script et suivez les invites interactives à l'écran :

~/Persistent/install_appimage.sh
