Tails OS AppImage Installer

Script modulaire et persistant pour gérer vos AppImages et raccourcis de menu

🛠️ Fonctionnement du script

Ce script gère le cycle complet d'installation d'une AppImage dans un environnement amnésique Tails OS :

1. Stockage

Enregistrement dans ~/Persistent/Apps/.

2. Dotfiles

Création du .desktop persistant dans TailsData_unlocked/dotfiles/.

3. Liaison & Menu

Création du lien symbolique dans ~/.local/share/applications/ et rafraîchissement GNOME.

📜 Le Script Bash (`install_appimage.sh`)

bash / install_appimage.sh 
#!/usr/bin/env bash
# ==============================================================================
# Assistant modulaire d'installation d'AppImage pour Tails OS avec Persistance
# ==============================================================================

# Dossiers de destination dans le stockage persistant et dotfiles
APP_DIR="$HOME/Persistent/Apps"
DOTFILES_DESKTOP_DIR="/live/persistence/TailsData_unlocked/dotfiles/.local/share/applications"
USER_DESKTOP_DIR="$HOME/.local/share/applications"

# 1. Vérification si la persistance est bien activée
if [ ! -d "$HOME/Persistent" ]; then
    echo "[!] Erreur : Le stockage persistant n'est pas activé ou déverrouillé."
    exit 1
fi

# Création des arborescences nécessaires
mkdir -p "$APP_DIR"
mkdir -p "$DOTFILES_DESKTOP_DIR"
mkdir -p "$USER_DESKTOP_DIR"

echo "=== Assistant d'installation AppImage pour Tails OS (Pro) ==="
echo ""

# 2. Menu de sélection du mode
echo "1) Télécharger une AppImage via une URL"
echo "2) Utiliser un fichier AppImage déjà présent"
read -rp "Choix [1/2] : " CHOICE

if [ "$CHOICE" -eq 1 ]; then
    read -rp "Entrez l'URL de l'AppImage : " APP_URL
    read -rp "Nom du fichier final (ex: MonApp.AppImage) : " APP_FILENAME
    
    # Correction de l'extension si absente
    [[ "$APP_FILENAME" != *.AppImage ]] && APP_FILENAME="${APP_FILENAME}.AppImage"
    
    DEST_PATH="$APP_DIR/$APP_FILENAME"
    echo "[*] Téléchargement en cours..."
    curl -L "$APP_URL" -o "$DEST_PATH"
    
elif [ "$CHOICE" -eq 2 ]; then
    read -rp "Chemin vers votre fichier .AppImage : " LOCAL_PATH
    
    # Nettoyage des guillemets éventuels
    LOCAL_PATH="${LOCAL_PATH//\'/}"
    LOCAL_PATH="${LOCAL_PATH//\"/}"

    if [ ! -f "$LOCAL_PATH" ]; then
        echo "[!] Fichier introuvable : $LOCAL_PATH"
        exit 1
    fi
    
    APP_FILENAME=$(basename "$LOCAL_PATH")
    DEST_PATH="$APP_DIR/$APP_FILENAME"
    
    if [ "$LOCAL_PATH" != "$DEST_PATH" ]; then
        cp "$LOCAL_PATH" "$DEST_PATH"
        echo "[*] Fichier copié dans $APP_DIR"
    fi
else
    echo "[!] Choix invalide."
    exit 1
fi

# Autoriser l'exécution de l'AppImage
chmod +x "$DEST_PATH"
echo "[+] Fichier rendu exécutable (chmod +x)."

# 3. Informations pour le raccourci .desktop
echo ""
echo "=== Configuration du raccourci dans le menu ==="
read -rp "Nom affiché dans le menu (ex: Feather Wallet) : " APP_NAME
read -rp "Nom du fichier .desktop (ex: feather.desktop) : " DESKTOP_FILENAME
read -rp "Catégorie (ex: Utility, Network, System) [Utility] : " APP_CAT
APP_CAT=${APP_CAT:-Utility}

read -rp "Chemin vers une icône perso (laisser vide pour icône par défaut) : " APP_ICON
# Nettoyage des guillemets
APP_ICON="${APP_ICON//\'/}"
APP_ICON="${APP_ICON//\"/}"

if [ -z "$APP_ICON" ]; then
    APP_ICON="utilities-terminal"
fi

[[ "$DESKTOP_FILENAME" != *.desktop ]] && DESKTOP_FILENAME="${DESKTOP_FILENAME}.desktop"

# Chemins cibles pour les dotfiles et le lien utilisateur
DOTFILES_FILE_PATH="$DOTFILES_DESKTOP_DIR/$DESKTOP_FILENAME"
USER_FILE_PATH="$USER_DESKTOP_DIR/$DESKTOP_FILENAME"

# 4. Génération propre du fichier .desktop dans le dossier source des dotfiles
cat < "$DOTFILES_FILE_PATH"
[Desktop Entry]
Version=1.0
Type=Application
Name=$APP_NAME
Exec=$DEST_PATH
Icon=$APP_ICON
Terminal=false
Categories=$APP_CAT;
EOF

chmod +x "$DOTFILES_FILE_PATH"

# 5. Création / Mise à jour du lien symbolique vers le profil actif
rm -f "$USER_FILE_PATH"
ln -s "$DOTFILES_FILE_PATH" "$USER_FILE_PATH"

# 6. Rafraîchissement de la base de données du bureau
update-desktop-database "$USER_DESKTOP_DIR"

echo ""
echo "=================================================="
echo "[✔] Installation et persistance configurées avec succès !"
echo "• AppImage stockée dans : $DEST_PATH"
echo "• Raccourci dotfiles    : $DOTFILES_FILE_PATH"
echo "• Lien actif utilisateur: $USER_FILE_PATH"
echo ""
echo "L'application est immédiatement disponible dans ton menu !"

🚀 Exécution dans Tails OS

1. Sauvegarder le script : cat << 'EOF' > ~/Persistent/install_appimage.sh (coller le code) puis EOF.

2. Rendre exécutable : chmod +x ~/Persistent/install_appimage.sh

3. Lancer : ~/Persistent/install_appimage.sh
