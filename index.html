Tails OS AppImage Installer

Modular and persistent script toolkit to seamlessly manage AppImages and application menu shortcuts

🛠️ How the Script Works

This automated script handles the complete installation and persistence cycle of any AppImage inside the amnesic Tails OS environment:

1. Persistent Storage

Stores and executes binaries safely inside ~/Persistent/Apps/.

2. Dotfiles Preservation

Saves persistent .desktop launchers directly to TailsData_unlocked/dotfiles/.

3. Linking & GNOME Menu

Builds live symbolic links in ~/.local/share/applications/ and refreshes the desktop database.

📜 Bash Script (`install_appimage.sh`)

bash / install_appimage.sh 
#!/usr/bin/env bash
# ==============================================================================
# Modular AppImage Installation Assistant for Tails OS with Persistence
# ==============================================================================

# Destination directories in persistent storage and dotfiles
APP_DIR="$HOME/Persistent/Apps"
DOTFILES_DESKTOP_DIR="/live/persistence/TailsData_unlocked/dotfiles/.local/share/applications"
USER_DESKTOP_DIR="$HOME/.local/share/applications"

# 1. Verify if persistence is enabled and unlocked
if [ ! -d "$HOME/Persistent" ]; then
    echo "[!] Error: Persistent storage is not enabled or unlocked."
    exit 1
fi

# Create necessary directories
mkdir -p "$APP_DIR"
mkdir -p "$DOTFILES_DESKTOP_DIR"
mkdir -p "$USER_DESKTOP_DIR"

echo "=== Tails OS AppImage Installation Assistant (Pro) ==="
echo ""

# 2. Mode selection menu
echo "1) Download an AppImage via URL"
echo "2) Use an existing local AppImage file"
read -rp "Choice [1/2] : " CHOICE

if [ "$CHOICE" -eq 1 ]; then
    read -rp "Enter AppImage URL : " APP_URL
    read -rp "Final filename (e.g., MonApp.AppImage) : " APP_FILENAME
    
    [[ "$APP_FILENAME" != *.AppImage ]] && APP_FILENAME="${APP_FILENAME}.AppImage"
    
    DEST_PATH="$APP_DIR/$APP_FILENAME"
    echo "[*] Downloading in progress..."
    curl -L "$APP_URL" -o "$DEST_PATH"
    
elif [ "$CHOICE" -eq 2 ]; then
    read -rp "Path to your .AppImage file : " LOCAL_PATH
    
    LOCAL_PATH="${LOCAL_PATH//\'/}"
    LOCAL_PATH="${LOCAL_PATH//\"/}"

    if [ ! -f "$LOCAL_PATH" ]; then
        echo "[!] File not found : $LOCAL_PATH"
        exit 1
    fi
    
    APP_FILENAME=$(basename "$LOCAL_PATH")
    DEST_PATH="$APP_DIR/$APP_FILENAME"
    
    if [ "$LOCAL_PATH" != "$DEST_PATH" ]; then
        cp "$LOCAL_PATH" "$DEST_PATH"
        echo "[*] File copied to $APP_DIR"
    fi
else
    echo "[!] Invalid choice."
    exit 1
fi

# Grant execution permissions to the AppImage
chmod +x "$DEST_PATH"
echo "[+] File marked as executable (chmod +x)."

# 3. Desktop shortcut configuration
echo ""
echo "=== Menu Shortcut Configuration ==="
read -rp "Display name in menu (e.g., Feather Wallet) : " APP_NAME
read -rp "Desktop filename (e.g., feather.desktop) : " DESKTOP_FILENAME
echo "Valid categories to prevent 'Other': Utility, Network, Development, Office"
read -rp "Category [Utility] : " APP_CAT
APP_CAT=${APP_CAT:-Utility}

# Fallback mapping for invalid user inputs
if [[ "$APP_CAT" =~ ^[Aa]ccessories$ ]]; then
    APP_CAT="Utility"
fi

read -rp "Path to custom icon (leave blank for default icon) : " APP_ICON
APP_ICON="${APP_ICON//\'/}"
APP_ICON="${APP_ICON//\"/}"

if [ -z "$APP_ICON" ]; then
    APP_ICON="utilities-terminal"
fi

[[ "$DESKTOP_FILENAME" != *.desktop ]] && DESKTOP_FILENAME="${DESKTOP_FILENAME}.desktop"

DOTFILES_FILE_PATH="$DOTFILES_DESKTOP_DIR/$DESKTOP_FILENAME"
USER_FILE_PATH="$USER_DESKTOP_DIR/$DESKTOP_FILENAME"

# 4. Clean .desktop file generation
cat << EOF > "$DOTFILES_FILE_PATH"
[Desktop Entry]
Version=1.0
Type=Application
Name=$APP_NAME
Exec=$DEST_PATH
Icon=$APP_ICON
Terminal=false
Categories=$APP_CAT;
EOF

chmod +x "$DOTFILES_FILE_PATH"

# 5. Create / Update symbolic link to active profile
rm -f "$USER_FILE_PATH"
ln -s "$DOTFILES_FILE_PATH" "$USER_FILE_PATH"

# 6. Refresh desktop application database
update-desktop-database "$USER_DESKTOP_DIR"

echo ""
echo "=================================================="
echo "[✔] Installation and persistence configured successfully !"
echo "• AppImage stored in     : $DEST_PATH"
echo "• Dotfiles shortcut      : $DOTFILES_FILE_PATH"
echo "• Active user symlink    : $USER_FILE_PATH"
echo ""
echo "The application is now immediately available in your app menu !"

🚀 Execution inside Tails OS

1. Save the script : cat << 'EOF' > ~/Persistent/install_appimage.sh (paste code) then EOF.

2. Make executable : chmod +x ~/Persistent/install_appimage.sh

3. Run it : ~/Persistent/install_appimage.sh
